# Options extraction report — Talimit Class 9–10 Math (step 1 only)

Source: `questions_merged.json` (3,720 rows, read-only, untouched). Output: `questions_with_options.json` (same 3,720 rows, same order, all 16 original fields byte-identical; an `options` field was added ONLY to MCQ rows). Non-MCQ rows (2,044) carry no `options` field. This step does NOT import anything to a DB, does NOT change any answer_key, and does NOT draw diagrams.

Method: every MCQ row was located by its `pdf_page` in `math-general.pdf` (942 pages, CamScanner scan) and its options were read visually from the rendered page image (200 dpi, 300 dpi for dense/formula pages), one page at a time, page by page. Garbled OCR question text was never used to invent options. Answer tables/grids/discs were never used as an options source. Where the page did not clearly show all options, the row's `options` is null and the row is flagged — nothing was guessed, borrowed from another item, or inferred from a key.

## Anomalies found (read before scoring)

### 1. Audit-required fulls — counted as full, but NOT clean

Workers differed in how strictly they treated number/page mismatches, so the final report splits fulls by confidence instead of hiding the difference:

- **ch16: 207 full = 139 clean (no notes) + 68 noted.** The noted set includes at least 14 number-discrepancy stem matches (row number vs a differently numbered printed item, matched on stem + distinctive values), at least 25 next-page sliver assignments (item fully on the next PDF page, not the row's `pdf_page`), thin/interleaved-OCR assignments, and 4 duplicate pairs. Thinnest three, named by the worker: p726-n49 (number + page only, stem not legible in OCR), p754-n73, p786-n23. Recommendation: do NOT score the 68 noted ch16 rows until they are spot-audited; the 139 clean rows need no such hold.
- **ch9 + ch11: 21 audit-noted fulls** (10 number-mismatch-noted, 11 spillover-noted where the item sits on an adjacent page by unique stem match; the two sets do not overlap). Same recommendation: spot-audit before scoring.
- **ch17 + ch0 and ch2 + ch7 duplicate pairs:** workers reported duplicate merged rows for the same printed item given the same options (ch16: 4 pairs, listed in the worker notes; ch17/ch0: at least 1 pair, e.g. printed Q16 of Model Test 08 to both p911-n16 and p912-n16; ch2/ch7: at least 2 pairs in ch7, p286-n6 and p294-n7). These are merged-file duplicates, not extraction errors, but step 2 should de-duplicate before scoring so one printed item is not scored twice.
- **ch3 off-by-one:** row p110-n133 is marked full, but its options were read from printed item 133 on PDF 135, not its row `pdf_page` 134 (noted in the worker entry; the row's `pdf_page` was NOT overwritten in this step). The guide repeats the same stem/option set as item 125; the recorded options are stated to be from item 133 itself.
