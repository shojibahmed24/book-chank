## Board-parser bugs found and fixed (verified on disk)

1. **colsplit gutter:** per-page boundary detection picked the wider gap between a right-column
   question NUMBER and its stem (~492) over the true gutter (~461), so right-column numbers
   landed in L and stems in R. Fix: use the file-median boundary (461.0) for every page
   (per-page value only trusted within 15pt of the median).
2. **ময়মনসিংহ header missed:** the file uses precomposed য় (U+09DF) while typed literals are
   decomposed — the board regex never matched. Fix: NFC-normalise the line, the regex, and the
   slug-dict keys.
3. **Index mismatch:** `drop_junk` re-indexed stream lines, but paper assignment compared
   against raw line indices — the last paper (ময়মনসিংহ) got 0 rows. Fix: skip junk inline,
   keep raw indices.
4. **Column leaks:** Q15/Q16 leak to R, Q17/Q18 leak to L. Fix: merge by question NUMBER per
   paper (not by stream), R groups by the number-drop rule.
5. **R re-enable too narrow:** the MCQ state machine only re-enabled on exactly Q17, so a
   paper whose Q13–Q16 leaked to R lost them. Fix: re-enable on N in 13..20.
6. **2025 উত্তরমালা header:** `উত্তরমালা(ঢাকা বোর্ড ২০২৫)` — not a bare line. Fix: startswith match.
7. **2024 key split layout:** numbers on one line, letters on the next. Fix: sequential
   number/letter pairing fallback (recovers Q1–7 + Q16–22 = 14/30 per paper).
