## Parser bugs found and fixed during this run

1. **RecursionError** in the memoized solver on Geography.doc (pathological segment, >1,000 tokens) — fixed with `sys.setrecursionlimit(20000)` + a greedy first-fit fallback for segments with >250 tokens.
2. **Duplicate ids** — board MCQ Q1–11 and CQ Q1–11 shared one id prefix; fixed by suffixing `-mcq` / `-cq` (ids are now `…-board-<slug>-<year>-mcq-<NNN>` / `-cq-<NNN>`).
3. **Lecture-sheet notes/CQ were 0** — header searches failed on (a) decode artefacts ("গুরুত্বপূর্ণ" is printed "গুরম্নত্বপূণর্") and (b) decomposed য়/ড় (decoder emits য+়, searches used precomposed য়). Fixed by NFC-normalizing the text and searching the artefact-free tail ("বিষয়গুলো সং"); the নিশ্চিত-কমন boundary now uses the occurrence after the question-bank header (the phrase also appears in the intro). Lecture-sheet CQ sections now parse with `cut_answers=False` (questions and printed answers are interleaved in one region; cutting at the answer header deleted the questions). Result: LS ch1 2 → 12 rows, ch2 4 → 34 rows; total lecture-sheet rows 324.
4. **Manifest is a dict** (`{"files": [...]}`), not a list — the driver iterated its 7 keys. Fixed to read `["files"]`.
5. **TP 2021/2022 missing** — `parse_tp_boards` deduped sections by board name only, keeping just the first year's paper per board. Fixed to dedupe by (board, year): TP01 100 → 300 rows, TP02 180 → 378 rows. Also NFC-normalized the TP text — the decomposed board name "ময়মনসিংহ" (54 rows) had gone into a wrong bucket file `board-board-2024.json` (deleted; those rows are now in `board-mymensingh-2024.json`).
6. **Spurious 2025 answer** — one Dinajpur 2025 MCQ row carried `answer_key: "ক"` from a ● marker although its options were scrambled away and the 2025 key grid is blank. Fixed: a ●-derived answer is cleared when the options are scrambled (key-grid answers are kept). 2025 `answer_key` is now 0, as the blank grids require.
7. **TP02 2021 MCQ uses Latin-digit markers** (`1.`–`30.`, 30 markers, only 5 Bengali) — added a fallback that converts Latin question markers to Bengali digits when no Bengali "১." exists (decimals and the subject code do not match the lookahead). ### 3. য+়/য় trap — 237 rows

`board_name` (and board-derived `set_id`, e.g. `ময়মনসিংহ-2021`) used decomposed য+় (U+09AF+U+09BC) instead of precomposed য় (U+09DF). Verified by codepoints: the string is NOT U+09DF, and NFC does not compose it — which is why the chunker never caught it. Fixed to precomposed য় on all 237 Mymensingh rows (47 newly flagged with the fix note; 190 already flagged). Same decomposed literal fixed in the chunker (`_work/parse.py` `BOARD_SLUGS` / `BOARD_NAME_FIX`, 2 lines — the chunker itself carried the decomposed form, which is why bucketing had worked). Decomposed য় persists in free text (question_text 2,064 / stimulus 677 / guide_solution 730 / flag_note 1,934 / chapter_name 268 rows — decoder output, e.g. বায়ুমণ্ডল, ভূগোল পরিচয়) — left as-is per the spec's keep-decode-artefacts-as-is rule.
