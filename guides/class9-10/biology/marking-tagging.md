## ৩. নমুনা-তালিকা (যা যা চোখে দেখা হয়েছে)

- কভার, সূচিপত্র + NCTB প্রশ্নকাঠামো (মুদ্রিত p. viii)
- চিত্র-সূচক (মুদ্রিত p. ১–২): অধ্যায়ভিত্তিক ছবি ও লেবেলযুক্ত চিত্র
- অধ্যায় ১: অনুশীলনমূলক কাজ (p. ১৮), MCQ ব্যাংক (p. ~২৩), সংক্ষিপ্ত Q&A (p. ৩৮, ৬০), সৃজনশীল (p. ৪৮, ৫৩, ৫৪, ৫৮), সাজেশন্স (p. ৬০), অধ্যায় মডেল টেস্ট (p. ৬১–৬২)
- কনসেপচুয়াল সৃজনশীল (p. ৫৫৪, ২২০ dpi-তে যাচাই)
- ব্যবহারিক সূচক ও মৌখিক অভীক্ষা (p. ৫৭৩)
- স্পেশাল মডেল টেস্ট ০৪ (p. ~৫৮৩)
- বোর্ড সৃজনশীল প্রশ্নপত্র: কুমিল্লা বোর্ড ২০২৩ সেট ০১ (p. ৬২৮), যশোর বোর্ড ২০২৩ সেট ০৩ (p. ৬২৬)

**সীমা:** অধ্যায় ১ গভীরভাবে + বাকি অংশ স্পট-নমুনা দেখা হয়েছে। অধ্যায় ২/৩/৪/১১/১২/১৩-এর ভেতরের পৃষ্ঠা পাতায় পাতায় দেখা হয়নি — সংগ্রহের সময় প্রতি অধ্যায়ে একই কাঠামো আছে কিনা যাচাই করতে হবে (বিশেষ করে অধ্যায় ১২-এর বংশগতি-ক্রস চিত্র ও অধ্যায় ২-এর কোষ-চিত্রে নতুন টাইপ আসতে পারে)।

## ৪. প্রশ্নের টাইপ (বইয়ে যা আছে)

| টাইপ | রূপ/লেআউট (নমুনা-প্রমাণ) |
|---|---|
| বহুনির্বাচনি (MCQ) | নম্বরযুক্ত প্রশ্ন, ৪টি অপশন (ক/খ/গ/ঘ)। অধ্যায়-ব্যাংকে সঠিক অপশনটি গোল-চিহ্নিত (circled key)। কিছু MCQ-এর পরে "তথ্য-ব্যাখ্যা" নোট। সাব-টাইপ: সাধারণ; বহু-বক্তব্য (i/ii/iii — "নিচের কোনটি সঠিক?"); চিত্র-ভাগাভাগি (একটি চিত্র থেকে ২–৩টি MCQ); উদ্দীপক-ভিত্তিক |
| সংক্ষিপ্ত-উত্তর প্রশ্ন | নম্বরযুক্ত "প্রশ্ন + উত্তর" জোড়া, পাঠ-উপশিরোনাম অনুযায়ী সাজানো (যেমন ১.৪ শ্রেণিবিন্যাসের বিভিন্ন ধাপ) এবং প্রতিটিতে পাঠ্যবই-পৃষ্ঠা ট্যাগ। উত্তরে মাঝে মাঝে ছক/ফ্লোচার্ট থাকে |
| জ্ঞানমূলক ও অনুধাবনমূলক | সাজেশন্স-টেবিলে (p. ৬০) এই দুটি ক্যাটাগরিতে প্রশ্ন-নম্বর তালিকাভুক্ত। সংক্ষিপ্ত প্রশ্নেরই জ্ঞান/অনুধাবন স্তর-বিভাজন — সংগ্রহে স্তর-ট্যাগ হিসেবে ধরতে হবে |
| সৃজনশীল (বোর্ড-ধাঁচ) | উদ্দীপক (লেখা/ছক/চিত্র/ফ্লোচার্ট) + ক/খ/গ/ঘ ৪টি অংশ, প্রতিটির ডান পাশে নম্বর মুদ্রিত। প্রতিটি গ্রুপের পূর্ণ মডেল উত্তর আছে, উত্তরের পাশে "শিখনফল" নম্বর। উৎস-ট্যাগ: বোর্ড+সাল বা স্কুল-নাম |
| সমন্বিত সৃজনশীল | একাধিক অধ্যায়ের সমন্বয়ে (নমুনা: "অধ্যায় ১ ও ৩ এর সমন্বয়ে প্রণীত") — চ্যাপ্টার-ট্যাগে বহু-অধ্যায় ধরা লাগবে |
| কনসেপচুয়াল সৃজনশীল | ধারণা-ভিত্তিক গ্রুপ; অংশ-সংখ্যা পরিবর্তনশীল (নমুনায় ক–চ = ৬টি অংশ); অংশের পাশে নম্বর মুদ্রিত নেই (২২০ dpi-তে যাচাই) |
| অনুশীলনমূলক কাজ | পাঠ্যবইয়ের কাজ (activity) + সমাধান; প্রায়ই চিত্র-নির্ভর (যেমন ৬টি চিত্র দেখে শাখা শনাক্ত করে তালিকা বানানো)। অ্যাপের ৫ টাইপের "অনুশীলনীমূলক কাজ"-এর সাথে মেলে |
| অধ্যায় মডেল টেস্ট | প্রতি অধ্যায়ের শেষে PART 04 "যাচাই ও মূল্যায়ন": MCQ ২৫ + সংক্ষিপ্ত + সৃজনশীল, পূর্ণাঙ্গ পরীক্ষার আদলে। সংক্ষিপ্ত/সৃজনশীল উত্তরের বদলে পৃষ্ঠা-পয়েন্টার ("উত্তরসূত্র") দেওয়া; MCQ-উত্তর শেষে কী-গ্রিড |
| স্পেশাল মডেল টেস্ট | পূর্ণ-বই পরীক্ষা (MCQ ২৫ + সংক্ষিপ্ত + সৃজনশীল), সেট-আকারে (নমুনা: মডেল টেস্ট ০৪) |
| বোর্ড প্রশ্নপত্র | বোর্ড+সাল+সেট-আকারে (নমুনা: কুমিল্লা ২০২৩ সেট ০১, যশোর ২০২৩ সেট ০৩)। উত্তর পুনর্মুদ্রিত নয় — পৃষ্ঠা-পয়েন্টার ("উত্তরসূত্র")। কিছু উত্তরে "পুনর্বিন্যাসকৃত পাঠ্যসূচি বহির্ভূত" ফ্ল্যাগ |
| ব্যবহারিক: পরীক্ষণ | ৬টি পরীক্ষণ (পেঁয়াজ-কোষ, অ্যামিবা, আলোর অপরিহার্যতা, ক্লোরোফিলের অপরিহার্যতা, শ্বসনে তাপ, ফুলের স্তবক) — ল্যাব-কাজ, প্রশ্ন-সারি নয় |
| ব্যবহারিক: মৌখিক অভীক্ষা | অধ্যায়ভিত্তিক ছোট Q&A (viva) — প্রশ্ন+উত্তর জোড়া |
| সাজেশন্স-টেবিল | প্রশ্ন-টাইপ নয়; গুরুত্ব-তারকা (৭★/৫★/৩★) দিয়ে প্রশ্ন-নম্বরের তালিকা — ট্যাগ হিসেবে ব্যবহারযোগ্য |

## ৫. নম্বর-বণ্টন (মুদ্রিত বনাম মুদ্রিত-নয় — স্পষ্টভাবে)

| অংশ | নম্বর (মুদ্রিত) |
|---|---|
| ক | ১ |
| খ | ২ |
| গ | ৩ |

| স্পেশাল মডেল টেস্ট | ৭৫ নম্বর, ৩ ঘণ্টা | মুদ্রিত (মডেল টেস্ট ০৪ হেডার) |
| বোর্ড সৃজনশীল প্রশ্নপত্র (পুরনো, ২০২৩) | ৫০ নম্বর, ২ ঘণ্টা ৩৫ মিনিট; "যে কোনো পাঁচটি প্রশ্নের উত্তর দিতে হবে" | মুদ্রিত (কুমিল্লা ২০২৩ সেট ০১, যশোর ২০২৩ সেট ০৩ হেডার) — ২০২৬-কাঠামোর (৪টি) সাথে মেলে না; সাল-ভেদে কাঠামো আলাদা |
| বোর্ড MCQ প্রশ্নপত্রের সময় | — | নমুনায় দেখা যায়নি (মুদ্রিত-নয়)। ৩ ঘণ্টা − ২ ঘণ্টা ৩৫ মিনিট = ২৫ মিনিট হিসাব মেলে, কিন্তু এটি গণনা, মুদ্রিত তথ্য নয় — সংগ্রহে যাচাই করতে হবে |
| কনসেপচুয়াল সৃজনশীলের নম্বর | — | মুদ্রিত নয় (২২০ dpi নমুনায় অংশের পাশে কোনো নম্বর নেই) → সংগ্রহে নম্বর NULL, কখনো বানানো যাবে না |
| মৌখিক অভীক্ষার প্রতি-প্রশ্ন নম্বর | — | মুদ্রিত নয় (কেবল মোট ৫ নম্বর মুদ্রিত) → প্রতি-প্রশ্ন নম্বর NULL |
| গ্রেড ব্যান্ড (মডেল টেস্ট মূল্যায়ন) | — | নমুনায় কোনো গ্রেড ব্যান্ড দেখা যায়নি (বাংলার মতো A/B/C/D ছক নেই) → সংগ্রহে না পেলে NULL; বানানো যাবে না |
| চিত্র-অঙ্কন উত্তরের আলাদা নম্বর | — | মুদ্রিত নয় (অংশের নম্বরের ভেতরেই ধরা) |

### ৫.৪ নম্বর যেভাবে মুদ্রিত থাকে (স্থানভেদে পার্থক্য)

- সৃজনশীল: প্রতিটি অংশের ডান পাশে নম্বর (ক ১, খ ২, গ ৩, ঘ ৪) — বোর্ড-ধাঁচ, অধ্যায়-ব্যাংক ও মডেল টেস্ট সবখানে একই।
- MCQ/সংক্ষিপ্ত: প্রতি-আইটেমে নম্বর নেই; মান কেবল কাঠামো-পৃষ্ঠা ও মডেল-টেস্ট হেডারে।
- মডেল টেস্ট: হেডারে মোট + সময় + প্রতি-অংশের মান; শেষে MCQ কী-গ্রিড + সংক্ষিপ্ত/সৃজনশীলের পৃষ্ঠা-পয়েন্টার (উত্তর পুনর্মুদ্রিত নয়)।
- বোর্ড প্রশ্নপত্র: হেডারে সময় + পূর্ণমান + নির্দেশনা; উত্তরের বদলে পৃষ্ঠা-পয়েন্টার।
- অধ্যায়-ব্যাংক MCQ: চাবি গোল-চিহ্নিত অপশনে (in-item); মডেল টেস্ট MCQ: চাবি শেষের গ্রিডে — চাবি-তোলার নিয়ম দুই জায়গায় দুই রকম।
- সাল-ভেদে পার্থক্য: ২০২৩ বোর্ড-পত্র = সৃজনশীল ৫×১০ = ৫০; ২০২৬ কাঠামো = সৃজনশীল ৪×১০ + সংক্ষিপ্ত ৫×২ = ৫০ (লিখিত)। সংগ্রহে প্রতি-পত্রের নির্দেশনা ও মোট যেমন মুদ্রিত তেমনই রাখতে হবে — নতুন কাঠামোয় নরমালাইজ করা যাবে না।

## ৬. চিত্র-নির্ভর প্রশ্ন (সবচেয়ে বড় ইস্যু)

জীববিজ্ঞানে চিত্র কেবল অলংকরণ নয় — প্রশ্নের মূল উপাদান। নমুনায় পাওয়া চিত্র-ব্যবহার:

| চিত্রের ভূমিকা | উদাহরণ (কাঠামো-মাত্র) |
|---|---|
| চিত্র-উদ্দীপক সৃজনশীল | চিত্র A/B/C দেখে রাজ্য শনাক্ত, গঠন ব্যাখ্যা, তুলনা, বিশ্লেষণ |
| চিত্র-ভাগাভাগি MCQ | একটি চিত্র (যেমন Fig-A ছত্রাক, অ্যামিবা) থেকে ২–৩টি MCQ |
| লেবেলযুক্ত চিত্র (সারাংশ/সূচক) | আদর্শ উদ্ভিদকোষ (২০+ লেবেল), মিয়োসিস ধাপ, সালোকসংশ্লেষণ-শ্বসন চক্র — চিত্র-সূচকে (p. ১–২) ও অধ্যায়-সারাংশে |
| ফ্লোচার্ট/ছক-উদ্দীপক | জীবজগৎ-বৃক্ষ, বংশগতি-ক্রস (RR/rr), খাদ্যশৃঙ্খল, লক্ষণ-শৃঙ্খল (X→Y→Z) — এগুলোর লেখা টেক্সটে তোলা যায় |
| চিত্র-অঙ্কন উত্তর | "চিহ্নিত চিত্র অঙ্কন কর" — উত্তরের দিকে চিত্র আঁকতে হয়; উত্তরের লেখায় ধাপ/লেবেল বর্ণনা থাকে |
| চিত্র-নির্ভর অনুশীলনমূলক কাজ | ৬টি চিত্র দেখে শাখা শনাক্ত করে তালিকা বানানো |

**পরিমাণ-ধারণা:** অধ্যায় ১-এর নমুনায় সৃজনশীল গ্রুপের বড় অংশই চিত্র-উদ্দীপক; MCQ-তেও চিত্র-ভাগাভাগি নিয়মিত। বাংলার ৬টি ছবি-সারির মতো সামান্য নয় — জীববিজ্ঞানে চিত্র-নির্ভর আইটেম ব্যাপক।

**বর্তমান বাধা:** অ্যাপে এখনো ছবি দেখানোর ব্যবস্থা নেই; বাংলা/ইংরেজিতে ছবি-উদ্দীপক HELD রাখার নিয়ম চলছে। জীববিজ্ঞানে একই নিয়ম চালালে ব্যাংকের বড় অংশ HELD হয়ে যাবে — তাই ছবি-প্রশ্নের সিদ্ধান্ত সংগ্রহের আগেই নিতে হবে (নিচে সিদ্ধান্ত-তালিকা দ্রষ্টব্য)।

**ট্যাগিং-প্রস্তাব (চিত্র):** `stimulus_kind` = text / table / picture / flowchart / diagram-labels / mixed; `picture_dependent` = true হলে ছবি ছাড়া প্রশ্ন অসম্পূর্ণ; `diagram_in_answer` = উত্তরে চিত্র/ছক/ফ্লোচার্ট আছে; ফ্লোচার্ট/ছক-উদ্দীপকের লেখা টেক্সট হিসেবে তোলা যাবে (ছবি নয়); লেবেলযুক্ত সারাংশ-চিত্রের লেবেল-তালিকা টেক্সট-চাংক হিসেবে তোলা যাবে।

## ৭. ট্যাগিং-প্রস্তাব (বর্তমান কনভেনশনের সাথে মিলিয়ে)

বাংলা: quiz / mcq-bank / short-qa / creative / model-mcq / model-creative / descriptive।
ইংরেজি: mcq / short / creative / true-false / writing-*।
গণিত: প্রতি-সমস্যা চাংক।

### ৭.১ সেকশন-মান (প্রস্তাবিত)

| সেকশন | কী ধরে |
|---|---|
| mcq-bank | অধ্যায়-ব্যাংকের MCQ (সাধারণ + বহু-বক্তব্য + চিত্র-ভাগাভাগি + উদ্দীপক-ভিত্তিক) |
| short-qa | সংক্ষিপ্ত প্রশ্ন+উত্তর (জ্ঞান/অনুধাবন স্তর-ট্যাগসহ) |
| creative | বোর্ড-ধাঁচ সৃজনশীল গ্রুপ (উদ্দীপক + ক/খ/গ/ঘ, ১/২/৩/৪) |
| conceptual | কনসেপচুয়াল গ্রুপ (পরিবর্তনশীল অংশ-সংখ্যা, নম্বর NULL) |
| activity | অনুশীলনমূলক কাজ + সমাধান (পাঠ্যবইয়ের কাজ) |
| model-mcq / model-short / model-creative | অধ্যায় মডেল টেস্ট ও স্পেশাল মডেল টেস্টের আইটেম (সেটের ভেতরে) |
| board-mcq / board-creative | বোর্ড প্রশ্নপত্রের আইটেম (সেটের ভেতরে; সাল-ভেদে কাঠামো আলাদা রাখতে হবে) |
| viva | মৌখিক অভীক্ষার Q&A (নম্বর NULL, ব্যবহারিক-ট্যাগ) |
| practical-chunk | পরীক্ষণ-বিবরণ (উদ্দেশ্য/উপকরণ/পদ্ধতি/পর্যবেক্ষণ) — সারি নয়, চাংক |

### ৭.২ প্রতি-সারির ফিল্ড (প্রস্তাবিত)

- `chapter` (১/২/৩/৪/১১/১২/১৩) + `combined_chapters` (সমন্বিত গ্রুপের জন্য, যেমন [১,৩])
- `lesson` (পাঠ-উপশিরোনাম, যেমন ১.৪) + `textbook_page` (পাঠ্যবই-পৃষ্ঠা ট্যাগ যেখানে মুদ্রিত)
- `source_kind`: exercise / board+year / school-test / special-model / board-paper / textbook-activity
- `board_tag` (যেমন রাজশাহী বোর্ড ২০২২), `school_tag` (স্কুল/কলেজ নাম)
- `stimulus_kind` + `picture_dependent` + `diagram_in_answer` (উপরে §৬)
- `marks` + `marks_parts` (সৃজনশীলে [১,২,৩,৪]) + `marks_source`: per-item (মুদ্রিত) / structure (কাঠামো-স্তর) / null (মুদ্রিত নয়)
- `cognitive_level`: জ্ঞান / অনুধাবন / প্রয়োগ / উচ্চতর (যেখানে মুদ্রিত/সাজেশন্স-টেবিলে আছে)
- `importance`: ৭★ / ৫★ / ৩★ (সাজেশন্স-টেবিল থেকে)
- `shikhonfol`: শিখনফল নম্বর (সৃজনশীল উত্তরের পাশে মুদ্রিত)
- `out_of_syllabus`: বইয়ের "পুনর্বিন্যাসকৃত পাঠ্যসূচি বহির্ভূত" ফ্ল্যাগ
- `answer_pointer`: মডেল-টেস্ট/বোর্ডের সংক্ষিপ্ত-সৃজনশীল উত্তরের পৃষ্ঠা-পয়েন্টার (মূল সারির সাথে লিংক করতে হবে)
- `key_format`: circled (ব্যাংক MCQ) / grid (মডেল টেস্ট MCQ)

### ৭.৩ সেট-নামকরণ (প্রস্তাবিত)

- অধ্যায় মডেল টেস্ট: `bio-ch<অধ্যায়>-model` (যেমন bio-ch1-model)
- স্পেশাল মডেল টেস্ট: `bio-special-model-<nn>` (যেমন bio-special-model-04)
- বোর্ড প্রশ্নপত্র: `bio-board-<বোর্ড>-<সাল>-set-<nn>` — লিখিত-পত্র ও MCQ-পত্র আলাদা সেট (সময়/নম্বর আলাদা বলে)
- বই/সাবজেক্ট: `subject_id = biology`, `book_id = class9-biology-bn-guide` (গণিত/ইংরেজির ধাঁচে; চূড়ান্ত সিদ্ধান্ত import-পর্যায়ে)

### ৭.৪ ব্যবহারিক অংশের আওতা (প্রস্তাব)

- ভেতরে: মৌখিক Q&A (viva সেকশন, নম্বর NULL) + ৬টি পরীক্ষণের বিবরণ (চাংক)।
- বাইরে: ১৫ নম্বরের ল্যাব-পারফরম্যান্স (যন্ত্র-ব্যবহার/পর্যবেক্ষণ/অঙ্কন/শনাক্তকরণ) — এটি প্রশ্ন-ব্যাংকের আইটেম নয়, স্কোর-প্রশ্ন হিসেবে তোলা যাবে না।

## ৮. ব্যবহারকারীর সিদ্ধান্তের তালিকা (সংগ্রহ শুরুর আগে লাগবে)
